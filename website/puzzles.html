How to read the distributions

Each column shows how a source’s answers are divided among solutions. Only correct human answers and valid model answers are included, so these percentages are not success rates. For each puzzle, human answers come from different participants; model answers come from independent calls using low effort and plain prompts: GPT-5.6 Sol, Claude Opus 4.8, and Gemini 3.5 Flash.

The tables show the study’s collected results. Each column gives the number of included answers (n); uncertainty intervals are not shown for individual puzzles.
